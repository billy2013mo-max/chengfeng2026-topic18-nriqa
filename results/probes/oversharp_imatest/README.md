# 无卡 Imatest 风格过锐探针 — 实验报告(2026-11-16)

**目的**:验证"Imatest 无卡化"特征(斜边 SFR / 边缘过冲/负下冲/振铃指数)能否提升**过锐**维度(当前 Nested OOF AP≈0.603,集成第一权重为 p1_qy 26.0%)的判别力。

**实现**:`code/probe_oversharp_imatest.py`(独立新文件,未改动任何现有代码)
- Canny+HoughLinesP 选长直边段(vertical/line >=92%),线段 span 内限定扫描
- 每行按亚像素边缘中心重对齐采样窗,8x 超采样 ESF binning
- LSF=Δ(ESF)(Hann 加权)→ 归一化 SFR;平台基准 overshoot/undershoot;低对比(<10/255)与脉冲边(单调相关<0.60)拒绝
- 对比 baseline 廉价物理:Laplacian 方差 / Tenengrad / 高频 P98

**数据**:3,573 张全量真图(8-fold split,过锐 gold:0:2290, 1:730, 2:328, 3:225),成对段测量成功 2,010 张(56%;线性域变体 1,969)。

Group-5-fold 逻辑回归(按 group_id 防视频泄漏,2,010 有边子集):
- base 廉价物理:AP_pos 0.590 / AP_p0 0.425
- base + 全部 Imatest 特征:AP_pos 0.590(无增益)/ AP_p0 0.419(略降)

**结论:负结果。** 边缘级 SFR/过冲特征在该数据上不携带超锐等级信息;全局锐度统计(Tenengrad 族)反而远强。

## 失败分析(为什么 Imatest 特征在这里无效)

1. **幸存者偏差**:56% 通过率,被拒的 44% 多为低对比/无长直边帧——过锐视频帧(超分/锐化管线产物)恰恰常缺"干净长直阶跃边",其过锐证据以**全局振铃/纹理**形式存在,不在孤立边带上。
2. **选边不对应缺陷载体**:Hough 偏向建筑/框架等结构边;过锐的主要载体(人脸边缘、文字笔画、细纹)多为脉冲型边或非直线,无法进入测量。
3. **等级语义**:"过锐 P0-P2" 是对全图观感的综合判断,单条边的 overshoot% 无法分辨 P1/P2(人为多级)的差别。
4. 尽管已按 Imatest 规范做线性化重测,结论不变(gamma 并非瓶颈)。

**建议**:若继续提升过锐,更值得投入的是(a)接入 v16 的 60 维物理通道的全局振铃统计(比对 9 成员版 W 中 p3_qy 曾占过锐 14.9% 的经验),或(b)用合成锐化数据(现有 SynthLab 管线)微调 p12_pe/ntg_pe 的过锐头——但二者均超出本探针范围。
