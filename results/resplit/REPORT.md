# 重划分验证：HPO 最优参数是否可迁移

## 实验设计

- 新划分 5 份（seed 11–15），每份与原始划分同规模（2073 / 500 / 1000）、
  同样按 source 分组（无跨集 source）、按「6 类标签存在性 × 分辨率桶」分层，
  类别与分辨率构成与原划分基本一致（test 的 P0 标签单元 611–629 vs 原始 654）。
- 固定参数：`triple(eupe:full + siglip2:lastk4 + cradio:lastk4)`,
  `clean_repeat=7, clean_penalty=0, lr_full=8.875e-5, lr_head=2.275e-3, wd=0.01,
  dropout=0, batch=6, epochs=4`（即 HPO run_046）。
- 每份划分跑 2 个训练 seed（1/2），共 10 次独立训练。
- 对照：旧 dual 基线 anchor（`clean_repeat=3, lr_full=2e-5, dropout=0.2, wd=0.05`，dual）在 seed 11/12 上各 2 seed。
- 阈值仍在各自划分的 val 上选，再评 test（与正式协议一致）。

- 对照 dual 基线：37.90 ± 5.60（s11 41.89，s12 33.91）→ best 领先 +3.6 ~ +7.5

## 唯一的失败点：S_clean 是刀尖指标

split12/seed2 = 38.33，其余分项都正常（S_pos 0.399、P0R 0.806），仅
`S_clean = 0.664`。原因是 **149 张 clean test 图里恰好 1 张被判 P0**：

- fpr = 1/149 = 0.0067，τ=0.02 → S_clean = 1 − 0.0067/0.02 = **0.664**，直接 −6.7 分
- 触发图：`200612820603_40.08s.png`（重度美颜/AI 质感人像），该图在 seed2 得 p0=0.80，
  在 seed1 只有 0.42，在对照模型上 0.18/0.79，在原始划分的模型上仅 **0.138**。
- 同一划分上对照模型触发了 2 次 clean 误报（149 张中 1 张、2 张），说明这是
  这批 clean 图本身的边界性，而不是本次参数的问题。

同类高风险的 clean 图（跨模型 p0 0.4–0.8）：

## 结论

1. 参数可迁移：4/5 个新划分、9/10 次训练的 test 落在 45.3–46.1，
   与原划分 45.66 几乎一致，S_pos / P0R / P0P 逐项复现。
2. 期望分数应按 **44.8–45.5** 估，而不是 45.7；尾部有 −7 分的 clean 误报风险（本次 1/10）。
3. 风险来源不是超参，而是 **clean 侧的少数边界图 + val 只有 61–79 张 clean
   导致阈值估计不稳**。这是下一步数据集工作的最高杠杆点。
