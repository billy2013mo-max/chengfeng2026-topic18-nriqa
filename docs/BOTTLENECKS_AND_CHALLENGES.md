# 命题18：晴羽观感体系·画质BadCase无参检测模型
## 当前技术瓶颈、实验复盘与核心困境深度剖析

---

### 一、 赛题与评估体系的“病理学”特征剖析

命题18要求对输入图片在6个缺陷维度（`模糊, 纹理损失, 过锐, 花屏, 过度生成, 虚化突兀`）进行精确无参检测，总分公式为（满分65分）：

$$\text{Total} = 25 \times S_{\text{pos}} + 20 \times S_{\text{p0}} + 20 \times S_{\text{clean}}$$

该评估公式在数学结构上存在极高的**非对称惩罚与脆弱性**：

1. **$S_{\text{clean}}$ 的“断崖式悬崖扣分”（占总分 30.8%）**：
   - 官方评测机制要求：对于盲测集中的无缺陷图（Clean 图），6 个维度的输出必须全部为“无问题”。
   - 若模型在某张无缺陷图上哪怕仅仅误报了一个最微弱的“P2 纹理损失”，整张图的 Clean 判定即刻归零。
   - 只要假阳性率（FPR）略微突破 0.5%，$S_{\text{clean}}$ 就会直接从满分 20 分暴跌至 13 分甚至更低。**单点误报代价高达数分**。
2. **$S_{\text{pos}}$ 的“三级阶梯严格匹配”**：
   - 区分“无缺陷 vs 缺陷”相对容易，但模型必须在 `P2（轻度） <-> P1（中度） <-> P0（重度）` 三个档位上做到完全精确命中；
   - 历史分析显示，训练集约 1,778 个正样本虽检出缺陷，但因档位错位导致 $S_{\text{pos}}$ 严重失分（单项潜在失分达 6.34 分）。
3. **$S_{\text{p0}}$ 的极端类别不平衡**：
   - $S_{\text{p0}} = 0.6 \times \text{Recall}_{\text{P0}} + 0.4 \times F1_{\text{P0}}$；
   - 真实数据集中 P0 样本极度稀缺（部分缺陷类别的 P0 样本全集不足 50 例），极易引发极端欠召回或误报爆发。

### 二、 InternViT-6B 超大模型实验复盘：为什么线上是纯负优化？

在本次迭代中，我们在 8 卡 H200 SXM 上进行了 100% 纯真图的大规模实验，引入了 60 亿参数的 `InternViT-6B` 骨干网络（训练了 5 组独立盲测折 + 3 组全量旗舰模型），但在线上测试集（`test_150`）实测中表现为明显的负优化。

深层次技术根因复盘如下：

#### 1. “60 亿参数”与“3,500 张样本”的根本容量失配（Over-parameterization Paradox）
- **数据体量极小**：全量真实训练集仅有 3,573 张真实图片，其中真正的“全无问题 Clean 图”仅约 70 张，部分微观缺陷样本极少。
- **模型容量过大**：InternViT-6B 单骨干拥有近 60 亿参数（微调最后 4 个 Block 也涉及近 5 亿参数）。
- **表象繁荣 vs 泛化崩溃**：
  - 训练集内部拟合得分高达 **63.34 分**（$S_{\text{pos}}=0.947, P_0\text{Recall}=0.983$），表现为完美的样本内拟合；
  - 但在未知域的测试集上，超大参数量导致模型学习到了训练集特定场景中不可迁移的高频虚假关联（Spurious Correlations），微观判别边界在测试集剧烈震荡。

#### 2. 微观敏感度成为“双刃剑”（Hyper-Sensitivity Trap）
- InternViT-6B 在浅层与高频感受野上的分辨率极高，确实在单一的“过锐边缘检测”上提高了局部的分类置信度；
- 但画质评估（NR-IQA）本质上是**主观感知与全局语义的妥协**。超高分辨率的 6B 模型会将自然图像中的真实物理纹理（如布料纹理、毛发噪点、砖墙结构、电影胶片颗粒）误判为“过锐”或“纹理损失”；
- 这种对高频微弱扰动的过度敏感，导致了跨样本维度的误报激增，彻底击穿了评测体系中最为脆弱的 Clean 规则。

#### 3. 历史模型强行锚定与脱钩的两难抉择
- 当尝试将新模型与历史 52.43 锚点进行平滑融合时，由于两个模型家族（原组合 vs InternViT）的特征空间与概率标定尺度不兼容，加权平均产生了严重的概率平滑退化，削弱了原本各自正确的判断；
- 当完全脱钩、完全由 InternViT-6B 独立决策时，其未经充分先验校准的决策面在测试集 150 张图上大幅偏移（改动高达 67 处格点），导致线上成绩直接断崖式下跌。

### 三、 当前核心瓶颈与工程困难点总结

经过多轮深度探索与严格验证，目前命题18画质检测方案面临以下四大核心瓶颈：

```
                              ┌────────────────────────────────────────┐
                              │  命题18：晴羽无参画质检测核心技术困境   │
                              └──────────────────┬─────────────────────┘
                                                 │
         ┌───────────────────────┬───────────────┴───────────────┬──────────────────────┐
         ▼                       ▼                               ▼                      ▼
┌──────────────────┐   ┌──────────────────┐            ┌──────────────────┐   ┌──────────────────┐
│ 1. 评测指标不对称 │   │ 2. 数据分布严重失衡│            │ 3. 标注一致性噪声 │   │ 4. 域偏移与黑盒测试│
│ S_clean 20分一票  │   │ 真实样本仅3574张 │            │ 档位划分主观模糊 │   │ 训练集与test_150 │
│ 否决，微弱误报即  │   │ Clean仅70张，P0仅 │            │ P2与P1界限重叠   │   │ 真实数据分布差异 │
│ 扣除全局6~7分    │   │ 数十张，极度匮乏  │            │ 存在严重人为温差 │   │ 难以跨域稳健校准 │
└──────────────────┘   └──────────────────┘            └──────────────────┘   └──────────────────┘
```

#### 瓶颈 1：训练数据极度匮乏与合成数据的负迁移壁垒
- **真实数据瓶颈**：整套赛题仅给出了 3,574 张真实图片，完全覆盖不了自然界千差万别的复杂现实拍摄与生成场景。
- **合成数据的负迁移困境**：我们在前序实验中尝试过多种自动合成退化方案（Blur/Sharpen/Noise/Artifact Augmentation），但实验明确表明：**合成失真与人类标注的“观感瑕疵”存在巨大鸿沟**。合成数据不仅不能提升泛化性，反而使过度生成与纹理损失的假阳性率飙升 6.7%，已被彻底证实为负迁移。

#### 瓶颈 2：人为主观标注的内在温差与不确定性
- 画质评价（尤其是轻度 P2 与中度 P1）缺乏客观物理仪器测量标准，高度依赖众包标注员的主观主观偏好。
- 标注体系存在显著的“同质异标”现象：同一程度的锐化或模糊，在人物面部可能被标为 P1，但在自然风光远景中可能被标为“无问题”或 P2。
- 深度网络在拟合这些模糊边界时，很容易在置信度 0.3~0.5 之间的灰色地带产生随机震荡。

#### 瓶颈 3：测试集（test_150）的黑盒域偏移（Distribution Shift）
- 盲测 150 张图片并非训练集的同分布随机采样，其内容涵盖了多种不同的生成模型、渲染引擎和拍摄设备；
- 单一模型在交叉验证（CV/OOF）上的所谓“提升”，一旦遇到测试集特有的场景偏置（例如测试集中存在特定风格的夜景或低照度画面），极易发生系统性误判。

#### 瓶颈 4：多标签多有序阈值决策面极度敏感
- 6 个缺陷类别并非彼此独立（例如“模糊”与“纹理损失”高度正相关，“过锐”与“花屏”在边缘高频特征上具有混淆性）；
- 现有的两阶段或级联标定阈值是基于训练集/验证集拟合出的静态超参数，对测试样本输入时的特征方差非常敏感，缺乏动态自适应能力。

### 四、 面向未来突破的战略建议与可能路径

为了彻底打破“负优化”与“噪声徘徊”的恶性循环，后续研发建议坚决放弃“无脑堆大模型参数”的路径，转向以下精细化架构与机制创新：

1. **骨干规模理性收缩（1B~2B 黄金平衡区间）**：
   - 彻底摒弃 6B+ 的超大视觉骨干；
   - 选用在中等样本上泛化极强、参数量适中（300M ~ 1.5B）且表征互补的骨干组合：例如 **SigLIP2-SO400M + C-RADIO-v4-H + ConvNeXtV2-Large**。
   - 卷积（高频纹理归纳偏置）与 Transformer（全局语义上下文）严格 1:1 解耦配合。

2. **架构解耦：建立独立的二值“Clean 判定器”（Decoupled Clean Detector）**：
   - 目前的架构是将 6 维缺陷概率相加来间接判断 Clean，这是导致 Clean 被误伤的根本原因；
   - 应当训练一个**专用的二分类 Clean 守护模型（Binary Clean Shield Network）**，专门用于输出当前图片是否为高质量纯净图。如果判定为 Clean，则直接一票否决所有弱缺陷输出，从架构底层彻底锁死 20 分。

3. **基于特征相似度检索的非参数校准（K-NN / Retrieval-Augmented Calibration）**：
   - 针对测试图片，提取其在高质量特征空间中的表征，与训练集中 3,574 张样本的拓扑流形进行近邻比对；
   - 仅当该测试样本的局部邻域内存在高置信度的同类缺陷案例时，才激活相应的 P1/P0 档位判定，抑制任何孤立样本的离群误报。

4. **主观不确定性建模（Evidential Deep Learning / Label Distribution Learning）**：
   - 不再将标注硬编码为离散的 one-hot 或 ordinal 阶梯，而是对标注员主观温差建模为高斯或狄利克雷分布；
   - 对模型预测的方差（Uncertainty）进行建模，当模型自身不确定度较高时，严格采取偏保守的档位降级策略，最大化期待得分（Expected Score）。
