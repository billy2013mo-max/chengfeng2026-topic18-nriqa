1.2$）或微小AIGC结构畸变（如手指多出一截残影），会直接触发P0（严重）或P1（中度）判定；反之，发生在背景树叶、远景砖墙或非显著纹理区域的同等甚至更强物理退化，在视觉掩蔽效应（Masking Effect）下往往仅被归为P2（轻微）甚至“无问题”。V15 在缺乏显著性主体与背景解耦的情况下直接施加像素级滤波并将其映射为固定等级标签，严重稀释并污染了真实数据中精细的语义-等级决策边界。其次，在非线性的8-bit sRGB空间直接施加滤波与噪声违背了相机图像信号处理（ISP）的物理成像过程。真实短视频与摄影图像中的模糊、散景光斑、传感器噪声、双边滤波涂抹（纹理损失）以及USM锐化白边（过锐），均发生在传感器线性辐照度空间（Linear Raw / Radiometrically Linear Space）或ISP流水线的特定阶段，随后才经过白平衡（AWB）、色彩校正矩阵（CCM）与非线性Gamma色调映射（Tone Mapping）转换至sRGB空间。直接在sRGB空间进行卷积核退化会导致高光区域能量截断与边缘频谱分布失真，使得深度视觉骨干（如 DINOv3-L、InternViT-6B）轻易通过高频统计捷径将合成图与真实图分离开来，产生严重的Sim2Real域间隙。此外，特征空间的线性或测地线插值（V14）无法对应离散的物理结构伪影。对于花屏（H.264宏块解码丢包）、虚化突兀（抠图深度边缘断层）以及AIGC过度生成（局部拓扑畸变与高频伪纹理）等高度非线性、空间局域化的结构性缺陷，在深度特征流形上对两张图像的表征向量进行插值，只会生成语义模糊的均值特征，无法教会模型识别真实的像素级瑕疵结构。2.2 结合逆向ISP流形与光学物理先验的四维连续分级合成配方为了在不引入Sim2Real偏差的前提下构建高保真训练样本，必须首先对3,573张真实标注集中的513张全维无损图（Clean Images）及各特定维度为“无问题”的真实高画质图像进行语义-几何-辐射度联合预解析。具体而言，利用 BiRefNet 提取像素级前景主体显著性掩码 $M_{\text{fg}} \in [0, 1]^{H \times W}$（结合人脸/人体关键点检测定位五官与手部核心敏感区 $M_{\text{core}}$），利用 Depth Anything V2 (Large) 提取高保真相对视差图 $D \in [0, 1]^{H \times W}$，并采用 Brooks 等人提出的逆向相机流水线（Unprocessing Camera Pipeline）将8-bit非线性sRGB图像 $I_{\text{sRGB}}$ 依次经过逆色调映射（Inverse Tone Mapping）、逆Gamma校正（$\gamma \approx 2.2$）、逆色彩校正矩阵（$\text{CCM}^{-1}$）与逆白平衡增益转换回16-bit线性传感器辐射度空间 $I_{\text{lin}}$：$$I_{\text{lin}} = f_{\text{AWB}}^{-1} \circ f_{\text{CCM}}^{-1} \circ f_{\text{Gamma}}^{-1} \circ f_{\text{Tone}}^{-1}(I_{\text{sRGB}})$$在此基础上，针对同一张种子图像 $I_{\text{seed}}$，严禁生成孤立的单一退化图，而必须沿着连续可控的物理参数轴，同步生成成对有序退化四元组（Ordered Degradation Quadruplets） $(I_{\text{Clean}}, I_{\text{P2}}, I_{\text{P1}}, I_{\text{P0}})$，使模型在同一场景内容下直接观察从无损、轻微、中度到严重的连续相变过程。在模糊（Blur）维度的合成中，必须摒弃简单的全局高斯模糊，在线性辐射度空间 $I_{\text{lin}}$ 中模拟真实的复合镜头离焦（Defocus Blur）与运动模糊（Motion Blur）。基于 Depth Anything V2 视差图 $D$，将对焦平面设定在前景主体均值深度 $d_f = \text{mean}(D[M_{\text{fg}} > 0.5])$ 上，随后人为引入对焦偏移量 $\Delta d$ 或非线性相机抖动轨迹核 $K_{\text{motion}}(L, \theta)$。每个像素的弥散圆（Circle of Confusion, CoC）半径由 $r_c(x,y) = A \cdot |d_f + \Delta d - D(x,y)|$ 决定，并通过圆盘/多边形光圈核或Zernike多项式波前衍射PSF进行空间可变卷积，最后经正向ISP还原为sRGB图像。在生成P2（轻微模糊）样本时，仅对前景主体区域 $M_{\text{fg}}$ 施加极小对焦偏移（主体CoC半径 $r_c \in [1.2, 2.2]\text{ px}$）或微运动核长度 $L \in [3, 5]\text{ px}$，保留主体宏观轮廓但轻微削弱睫毛、发丝等像素级微结构；在生成P1（中度模糊）样本时，将主体区域CoC半径扩展至 $r_c \in [2.8, 5.0]\text{ px}$ 或非线性运动轨迹核 $L \in [7, 12]\text{ px}$，使前景高频边缘梯度下降 $35\% \sim 55\%$，但尚未出现重影分裂；而在生成P0（严重模糊）样本时，将主体区域CoC半径拉大至 $r_c \in [6.5, 15.0]\text{ px}$ 或施加剧烈运动模糊 $L \in [16, 35]\text{ px}$，并叠加高光饱和溢出（Highlight Blooming），使核心主体完全丧失辨识度。在纹理损失（Texture Loss / 涂抹塑料感）维度的合成中，需精准还原短视频中的物理退化成因：涂抹塑料感并非单纯的低通模糊，而是移动设备在暗光或高倍率变焦下，ISP降噪模块（3DNR/双边滤波）与AI美颜或超分模型（如 DiffBIR、PASD 在降噪模式下）对高频纹理的过度抹除，常伴随锐利的伪边缘保留，呈现“边缘尚清但内部皮肤或衣物如塑料般平滑”的视觉特征。合成流程首先在 $I_{\text{lin}}$ 空间依据传感器物理噪声模型 $\sigma^2(x) = \lambda_s x + \lambda_r$ 注入泊松-高斯（Shot-Read）异构噪声，随后在色度与亮度通道级联高强度保边滤波器（导向滤波 Guided Filter $\text{GF}(r, \epsilon)$、非局部均值 NLM 与双边滤波 Bilateral Filter），并叠加H.264/HEVC高CRF量化压缩或轻量级扩散降噪器重绘。对于P2（轻微涂抹），设置导向滤波半径 $r=4, \epsilon = 0.005^2$，仅在非显著边缘区域（梯度幅值 $|\nabla I| < \tau_{\text{edge}}$）混合 $\alpha = 0.45$ 的滤波结果，叠加H.264 $\text{CRF}=28$ 重编码，轻微抹平皮肤毛孔与织物细微颗粒；对于P1（中度涂抹），采用双边滤波 $\sigma_{\text{color}} \in [25, 45], \sigma_{\text{space}} \in [7, 11]$ 结合 $2\times$ 下采样后再经双三次插值与保边锐化回放（混合比 $\alpha = 0.75$），叠加H.264 $\text{CRF}=33$，形成典型的短视频平台中度“磨皮塑料感”；对于P0（严重涂抹），则施加多级均值漂移（Mean Shift）或极强导向滤波（$r=12, \epsilon = 0.04^2, \alpha = 0.95$）配合 Real-ESRGAN 二阶退化链中的高倍下采样重整，彻底消除主体与背景的中高频自然随机纹理，呈现油画化或蜡像化伪影。在过锐（Oversharpening / 锐化白边伪影）维度的合成中，重点模拟短视频转码器与老片修复流水线通过自适应非锐化掩蔽（Unsharp Masking, USM）或拉普拉斯高频增益强行提升主观清晰度所引发的副产物，即在高对比度边缘两侧产生亮白边（Overshoot Halo）与暗黑边（Undershoot Halo）振铃伪影，以及平坦区域的噪点颗粒硬化。合成算子定义为：$$I_{\text{sharp}} = \text{Clip}_{[0,1]}\left(I + \lambda_1 (I - G_{\sigma_1} * I) + \lambda_2 \cdot M_{\text{edge}} \odot \text{sign}(I - G_{\sigma_2} * I) \cdot |I - G_{\sigma_2} * I|^{\gamma_s}\right)$$其中 $G_{\sigma}$ 为高斯低通核，$\lambda_1, \lambda_2$ 控制高频增益与非线性边缘过冲强度。在生成P2（轻微过锐）时，设置 $\sigma_1 = 1.0, \lambda_1 \in [0.8, 1.3], \lambda_2 = 0$，使边缘对比度偏硬，放大检视发丝与文字边缘可见宽度约 $1\text{ px}$ 的微弱亮边，但无大面积光晕扩散；在生成P1（中度过锐）时，设置 $\sigma_1 = 1.5, \lambda_1 \in [1.6, 2.5], \sigma_2 = 2.5, \lambda_2 \in [0.3, 0.6]$，在人物轮廓、建筑天际线等强边缘两侧形成宽度 $1.5 \sim 2.5\text{ px}$ 的明显白边光晕，同时背景暗部微噪点被放大为椒盐状硬颗粒；在生成P0（严重过锐）时，级联两轮USM（$\lambda_1 \in damaged.ts 损坏非关键帧（P帧）数据包载荷，再通过软解码提取出现真实16×16宏块错位、局部马赛克涂抹与色彩断层的受损帧。另一方面，在YUV420p原始字节流中随机选取连续的宏块行（Slice），将其U/V色度分量全部置零（在YUV空间中 $Y=0, U=0, V=0$ 映射到RGB空间即为典型的刺眼亮绿屏）或随机翻转字节位，从而逼真复现硬件解码器缓冲区溢出导致的底部或局部绿屏与彩色条带花屏。针对虚化突兀（Abrupt Bokeh，仅P0），根据 BokehDiff 与 Dr. Bokeh 的光学建模研究，真实的光学散景（Lens Blur）遵循连续的深度视差过渡与前景边缘半透明混合；而智能手机人像模式或直播实时背景虚化之所以产生“虚化突兀（P0）”缺陷，正是因为分割或深度估计模型在复杂边缘（如蓬松头发、眼镜框、手指缝隙、弯曲手臂形成的闭合镂空区）发生预测错误，导致前景被误切模糊，或者背景区域紧贴主体边缘处缺乏渐进过渡而呈现“剪纸贴图感”。为合成高保真“虚化突兀_P0”正例，首先提取包含清晰人物或前景物体的Clean图像，获取 的随机非对称膨胀（使主体外围残留一圈清晰背景光边）或腐蚀（将人物耳朵、发丝或肩部边缘直接咬掉并卷入背景强模糊）；其二是利用连通域分析找出被手臂、双腿或发丝包围的背景小连通域（面积 $< 3\%$），强制将其掩码置为前景，制造“全图背景严重虚化、唯独腋下或手指间背景完全清晰锐利”的典型抠图漏检伪影；其三是无视地面深度的连续渐变，仅保留人物掩码清晰，而对人物脚底接触的同一深度平面地面施加半径 $r_c \in [18, 35]\text{ px}$ 的圆盘强虚化，制造强烈的空间悬浮与断层感。与此同时，针对同一张种子图像，使用原始未破坏的 Depth Anything V2 连续视差图 $D$ 与 BiRefNet 亚像素级软掩码 $\alpha_{\text{gt}}$，严格按照物理弥散圆公式 $r_c(k) = A \cdot |d_f - D(k)|$ def verify_synthetic_quadruplet_with_vlm(vlm_engine, img_clean, img_p2, img_p1, img_p0, crop_coords, target_dim):
    """
    输入同一语义种子生成的 (Clean, P2, P1, P0) 四元组及其核心主体1:1裁剪块，
    执行相邻等级成对偏好校验与跨维度污染检测。
    """
    pairs = [("P2_vs_Clean", img_clean, img_p2, "P2"),
             ("P1_vs_P2",    img_p2,    img_p1, "P1"),
             ("P0_vs_P1",    img_p1,    img_p0, "P0")]
    
    for pair_name, img_low, img_high, expected_grade in pairs:
        # 构造包含全局图与局部1:1高分块的视觉输入序列
        crops_low = extract_focus_crops(img_low, crop_coords, size=448)
        crops_high = extract_focus_crops(img_high, crop_coords, size=448)
        
        user_query = (
            f"请专门针对【{target_dim}】维度对比图像A与图像B（已附带主体核心区1:1放大块）。\n"

        )
        # 提取VLM对关键判定词的Token概率进行软阈值截断

            system=SYSTEM_PROMPT, images=[img_low, crops_low, img_high, crops_high], prompt=user_query

    switch_margin_pts=0.015,
    max_iter=50
):
    """
    面向65分制官方指标的贝叶斯最优期望宏F1与P0召回联合坐标交换解码器。
    彻底废除 PhaseA KAPPA_P1P2 惩罚与 Top-K 预算控制器。
    
    参数:
        probs_dict: dict, 包含6个维度的校准后互斥概率矩阵:
            - 全分级维度 ('blur', 'texloss', 'oversharp', 'overgen'): shape (N, 4), 列顺序为 [0:无问题, 1:P2, 2:P1, 3:P0]
            - 仅P0维度 ('screenart', 'bokeh'): shape (N, 2), 列顺序为 [0:无问题, 1:P0]
        anchor_preds_dict: dict (可选), 52.89最高分锚点的离散预测标签，用于施加信任域边际阈值保护。
        shield_top_m: int, Clean Shield 保护的候选无损图数量 (默认测试集150张中保护Top-28张绝对不报P0)。
        switch_margin_pts: float, 相较于52.89锚点翻转单个单元格所需的最小期望总分净增益 (单位: 分)。
    返回:
        final_preds: dict, 6个维度的最优离散预测数组。
    """
    full_dims = ['blur', 'texloss', 'oversharp', 'overgen']
    p0_only_dims = ['screenart', 'bokeh']
    all_dims = full_dims + p0_only_dims
    N = probs_dict['blur'].shape[0]

    # 1. 计算全局 Clean Shield 保护集合 S_shield (防止触发 20分 S_clean 悬崖归零)
    log_p_clean = np.zeros(N, dtype=np.float64)
    for d in all_dims:
        log_p_clean += np.log(np.clip(probs_dict[d][:, 0], 1e-7, 1.0))
    p_clean_rank = np.argsort(-log_p_clean)
    clean_shield_mask = np.zeros(N, dtype=bool)
    clean_shield_mask[p_clean_rank[:shield_top_m]] = True

    final_preds = {}

    # 2. 逐维度精确最大化65分制期望得分贡献 U_c(y)
    for d in all_dims:
        P = np.asarray(probs_dict[d], dtype=np.float64)
        K = P.shape[1] # 全分级 K=4, 仅P0 K=2
        p0_idx = K - 1

        # 计算各等级期望真实正例总数 T_k = sum_i P(y_i = k)
        T_k = np.sum(P, axis=0) + 1e-7

        # 精确设定官方65分制下各通道的权重 (单位: 客观总分点数)
        if d in full_dims:
            # k=0(无问题): 0分; k=1(P2): 25/18分; k=2(P1): 25/18分; k=3(P0): F1占(25/18 + 8/6)分, Recall占2.0分
            w_f1 = np.array([0.0, 25.0 / 18.0, 25.0 / 18.0, 25.0 / 18.0 + 8.0 / 6.0])
            w_rec_p0 = 2.0
        else:
            # 仅P0维度: k=0(无问题): 0分; k=1(P0): F1占(25/6 + 8/6)=5.5分, Recall占2.0分
            w_f1 = np.array([0.0, 25.0 / 6.0 + 8.0 / 6.0])
            w_rec_p0 = 2.0

        # 初始化预测：若提供52.89锚点则从锚点热启动，否则从校准后 argmax 启动
        if anchor_preds_dict is not None and d in anchor_preds_dict:
            y_pred = np.array(anchor_preds_dict[d], dtype=int).copy()
        else:
            y_pred = np.argmax(P, axis=1)

        # 强制执行 Clean Shield 约束：保护集内的图像禁止预测为 P0
        for i in range(N):
            if clean_shield_mask[i] and y_pred[i] == p0_idx:
                y_pred[i] = np.argmax(P[i, :p0_idx])

        # 统计当前各等级预测计数 Pred_k 与期望真阳性 TP_k
        pred_counts = np.bincount(y_pred, minlength=K).astype(np.float64)
        tp_k = np.array([np.sum(P[y_pred == k, k]) for k in range(K)], dtype=np.float64)

        def compute_dimension_expected_score(counts, tps):
            f1_k = (2.0 * tps) / (counts + T_k)
            rec_p0 = tps[p0_idx] / T_k[p0_idx]
            return np.sum(w_f1 * f1_k) + w_rec_p0 * rec_p0

        # 坐标交换迭代求解全局最优离散分配
        for _ in range(max_iter):
            changed = False
            base_score = compute_dimension_expected_score(pred_counts, tp_k)

            for i in range(N):
                cur_c = y_pred[i]
                best_c = cur_c
                best_gain = 0.0

                for cand_c in range(K):
                    if cand_c == cur_c:
                        continue
                    # Clean Shield 硬约束拦截
                    if clean_shield_mask[i] and cand_c == p0_idx:
                        continue
                    # 稀有仅P0维度的高危FP防线：无问题升P0需满足后验概率 >= 0.60
                    if d in p0_only_dims and cand_c == p0_idx and P[i, p0_idx] < 0.60:
                        continue

                    # 试算将样本 i 从 cur_c 移至 cand_c 后的新统计量
                    new_counts = pred_counts.copy()
                    new_tps = tp_k.copy()
                    new_counts[cur_c] -= 1.0
                    new_tps[cur_c] -= P[i, cur_c]
                    new_counts[cand_c] += 1.0
                    new_tps[cand_c] += P[i, cand_c]

                    new_score = compute_dimension_expected_score(new_counts, new_tps)
                    gain = new_score - base_score

                    # 若存在锚点且偏离锚点预测，需扣除信任域边际门槛 switch_margin_pts
                    if anchor_preds_dict is not None and d in anchor_preds_dict:
                        anchor_c = anchor_preds_dict[d][i]
                        if cur_c == anchor_c and cand_c != anchor_c:
                            gain -= switch_margin_pts
                        elif cur_c != anchor_c and cand_c == anchor_c:
                            gain += switch_margin_pts

                    if gain > best_gain + 1e-6:
                        best_gain = gain
                        best_c = cand_c

                if best_c != cur_c:
                    # 执行精确状态更新
                    pred_counts[cur_c] -= 1.0
                    tp_k[cur_c] -= P[i, cur_c]
                    pred_counts[best_c] += 1.0
                    tp_k[best_c] += P[i, best_c]
                    y_pred[i] = best_c
                    base_score = compute_dimension_expected_score(pred_counts, tp_k)
                    changed = True

            if not changed:
                break

        final_preds[d] = y_pred

    return final_preds
