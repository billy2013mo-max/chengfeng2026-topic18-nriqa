## 一、 数据集统筹拆分与零泄漏交叉验证方案

严格遵循命题文档第 5 节与第 7 节要求（*“参赛者自行从首批训练/测试集和补充数据集中划分训练集、验证集和测试集，鼓励采用交叉验证检验泛化能力，按来源视频或相似场景分组，避免数据泄漏”*），我们统筹全部 **3,573 张公开开发真图**（首批 `1,902` 张 + 补充数据集 `1,671` 张），构建了严格零泄漏的 **8-Fold 场景隔离交叉验证体系（`Fold 0 ~ Fold 7`）**：

1. **按来源视频/场景分组分层（Group Stratified 8-Fold）**：
   - 将全部 `3,573` 张真图按来源视频标识与相似场景聚类分组，并按 14 维多标签组合分层切分为 8 个互斥折；
   - 同一视频或高度相似场景的所有帧严格落在同一折内，彻底杜绝相邻帧跨折泄漏；
   - 训练过程中 **绝不将文件名或路径特征作为模型输入**。
2. **严格嵌套 Out-Of-Fold（Nested OOF）评测协议**：
   - 每折模型仅使用 87.5%（7 折）真图及该折内构造的辅助数据训练，并在剩余 12.5%（1 折）真图上做盲测推理；
   - `RoutedEUDecoder` 的温度缩放参数与期望效用权重同样在 **嵌套内循环（Nested OOF）** 上拟合，再在外折评估，保证 **3,573 张真图的全部自评测分数 100% 零泄漏**；
   - 140/150 张公开打榜集仅作最终独立推理参考，绝不用于任何阈值调优或分布校准。
