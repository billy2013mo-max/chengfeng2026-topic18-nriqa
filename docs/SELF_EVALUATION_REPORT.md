## 一、 数据集统筹拆分与零泄漏嵌套交叉验证协议

严格遵循命题文档第 5 节与第 7 节要求（*“参赛者自行从首批训练/测试集和补充数据集中划分训练集、验证集和测试集，鼓励采用交叉验证检验泛化能力，按来源视频或相似场景分组，避免数据泄漏”*），本方案统筹全部 **3,573 张公开人工标注真图**（首批 `orig` `1,902` 张 + 补充数据集 `supp` `1,671` 张），建立了严格零泄漏的 **8-Fold 场景隔离嵌套交叉验证体系（`Fold 0 ~ Fold 7`）**：

1. **按来源视频与相似场景聚类分组（Group-Stratified 8-Fold）**：
   - 将全部 `3,573` 张真图按来源视频 ID 前缀与感知相似度聚类分组，并按 14 维正向（缺陷 × 等级）多标签组合分层切分为 8 个互斥折（[`data/qingyu_splits/`](file:///wanqing-develop/luowenjing/18/data/qingyu_splits)）；
   - 同一视频剪辑或高度相似场景的所有抽帧 100% 落在同一折内，杜绝相邻帧跨折泄漏；
   - 训练与推理全过程 **100% 屏蔽文件名、目录路径与批次标签特征（Tag-Free）**。
2. **严格双层嵌套盲测（Nested Out-Of-Fold）协议**：
   - **第一层（模型层）**：每折专精模型及同折合成负例（`peg` 码流花屏、`pe_bkseg1` 抠图散景、序数退化阶梯）仅由其余 7 折（87.5%）真图构造训练，在留出折（12.5%）上推理汇总出 `3,573` 张全量零泄漏 OOF 概率；
   - **第二层（校准与解码层）**：`RoutedGateEUDecoder`（温度缩放、分维路由 `W`、`DirDiag`）、`deconf_v4_tile`（`过锐` 11 维 1:1 显微镜校准 + `过度生成` 24 维 `ntg_pe` 1:1 切片局部尖峰与前景/解剖去混淆校准 + `虚化突兀` 散景协同门控 `BokehSynergyV3` + 双向 Clean 锁死）以及 `TrueGateConstrainedEU` 期望效用阈值，均在 **外折留出前的 7 折内层分组 CV** 上独立拟合，再在外折上做纯粹盲测评分；
   - 公开打榜集（`test_150`）与终评集（`final_644`）仅作最终一次性前向推理，**绝不参与任何超参选择、阈值微调或后验分布校准**。

1. **真实多帧视频 OOF 对比**：
   - 传统多帧概率均值平滑（Legacy Mean/CUSUM）：视频级 `P0` 召回率仅 `74.37%`（视频 `Doc2_Strict = 51.215`），容易漏检短时局部花屏与崩坏；
   - **`EffectiveFrameORVideoAggregator`（本方案）**：视频级 `P0` 召回率高达 **`84.45%`**（提升 **`+10.08%`**），Clean 多帧视频特异度达 **`100.0%`（0 误报）**，视频 `Doc2_Strict` 达 **`51.922`**。
2. **随抽帧数 $M$ 增长的误报抑制效果**：
   - 在高密度抽样 `M = 8 / 16 / 30` 帧下，将 Clean 视频任意缺陷误报率较朴素逐帧 OR 分别压低 **`3.4×`（`6.07% → 1.80%`）**、**`2.8×`（`11.23% → 4.07%`）** 与 **`2.6×`（`19.63% → 7.67%`）**。
